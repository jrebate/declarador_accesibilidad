# Declarador de accesibilidad

Generador gratuito de declaraciones de accesibilidad en español. Sigue la estructura del modelo oficial del Real Decreto 1112/2018 (sector público) y ofrece una variante para empresas sujetas a la Ley 11/2023.

- Autoevaluación con WCAG 2.2 (55 criterios A y AA, EN 301 549 V4.1.1) o WCAG 2.1 (50 criterios); la situación de cumplimiento se calcula sola (lo no evaluado cuenta como no conforme).
- Todo funciona en el navegador: un único `index.html`, sin dependencias ni servidor.
- Analítica sin cookies con GoatCounter.

La herramienta da formato a lo que declara cada entidad. No analiza webs, no sustituye una auditoría y no certifica el cumplimiento.
